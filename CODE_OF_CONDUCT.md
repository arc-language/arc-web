# Code of Conduct

## Our pledge

The Arc project is committed to fostering a welcoming, respectful, and harassment-free community for everyone — regardless of background, experience level, identity, or expression.

## Standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The canonical text is maintained at the link above; please read it in full.

In summary:
- **Treat people with respect.** Disagreements are technical; people are people.
- **Assume good faith.** Most problems are misunderstandings, not malice.
- **Keep discussions focused.** Be constructive, on-topic, and welcoming to newcomers.
- **Step back when asked.** Maintainers may ask contributors to pause or adjust their participation.

## Scope

This Code of Conduct applies in all project spaces — issues, pull requests, discussions, code reviews, the project Discord (when established), and any direct communication tied to Arc.

It also applies when an individual is officially representing the project in public spaces — using a project email, posting on social media as a maintainer, or speaking at an event on behalf of Arc.

## Reporting

If you observe a violation, or experience one yourself, please report it privately:

- **Email:** `conduct@arc-language.dev` (replace with the actual maintainer contact)
- Reports are confidential. Only the maintainers reviewing the report will see its contents.

## Enforcement

Maintainers will review every report and respond within 7 days. Possible outcomes include:

| Level | Response |
| --- | --- |
| 1. Correction | Private clarification of why the behavior was problematic |
| 2. Warning | Documented warning; may include a temporary ban from project spaces |
| 3. Temporary ban | Time-limited ban from all project communication channels |
| 4. Permanent ban | Permanent removal from the project community |

Maintainers will follow the [Contributor Covenant Enforcement Ladder](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) when deciding outcomes.
